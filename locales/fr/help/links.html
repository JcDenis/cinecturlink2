Les livres, films, albums, sites web que vous aimez, affichés sur le blog par des widgets et par une page publique.

Liens
Cliquez sur un titre pour modifier le lien. Sélectionnez des liens pour changer leur évaluation ou leur catégorie, ou pour les supprimer.
Filtres
Filtrez par catégorie ou par titre, et choisissez le tri et le nombre de liens par page. Les colonnes se choisissent dans vos préférences.
Sur le blog
Activez le plugin, choisissez le dossier des images et activez la page publique dans les paramètres du blog. Ajoutez les widgets depuis la page « Widgets ».
